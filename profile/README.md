## Open source

**[Novra for Mac](https://github.com/Naqara-Dev/novra)**: a free Mac cleaner that shows what's taking space, what each thing is for, and what happens if you remove it.
Swift 6 and SwiftUI, MIT licensed. Issues, translations and new cleanup rules are welcome.
